# Sagalpreet Singh — Personal Portfolio

A modern, responsive, and high-performance portfolio website built with **React**, **TypeScript**, and **Vite**.

Designed for Sagalpreet Singh, a Computer Science & Engineering undergraduate specializing in cybersecurity, network traffic analysis, software development, and system architecture.

## 🚀 Features

- **Dynamic Interactive UI**: Real-time custom cursor with 0-delay tracking and tactile micro-interactions.
- **Modern Typography & Glassmorphism**: Clean layout with Space Grotesk, Inter, and JetBrains Mono.
- **Comprehensive Sections**:
  - **Hero**: Profile picture, headline, current status badge, and quick actions.
  - **About**: Core competencies across security, software development, and systems.
  - **Technical Skills**: Filterable skills catalog (Cybersecurity, Development, Tools, Core Concepts).
  - **Experience**: Cybersecurity Research Intern timeline at ShadowFox.
  - **Featured Projects**: Interactive modals with architecture breakdowns and repository links (Vanguard ID, Jal-Chakra, AI Voice Assistant).
  - **Education & Certifications**: Guru Nanak Dev Engineering College (GNDEC), NPTEL, and IBM credentials.
  - **Leadership**: SIH Hackathon leadership, cultural community contributions.
  - **Contact**: Email copy with feedback toast and direct outreach links.
- **Accessibility & SEO**: Semantic HTML5, ARIA labels, meta descriptions, and responsive design for all screen sizes.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite 8
- **Icons**: Lucide React + custom SVG icons
- **Animations**: CSS transitions + hardware-accelerated transforms
- **Styling**: Vanilla CSS design system with CSS custom properties

## 💻 Getting Started Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/preetsagal7/Portfolio.git
   ```

2. Navigate into the project directory:
   ```bash
   cd Portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
